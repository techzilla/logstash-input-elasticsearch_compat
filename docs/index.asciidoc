=== Elasticsearch compat input plugin

include::{include_path}/plugin_header.asciidoc[]

==== Description

Receives Elasticsearch Bulk API requests and emits one Logstash event per `index` or `create`
action. Point a client that normally writes to Elasticsearch, such as the OpenTelemetry
Collector `elasticsearch` exporter (tested with its default settings), at Logstash instead.

This plugin is a protocol-compatible receiver, not an Elasticsearch node.

===== Routes

* `POST` or `PUT` `/_bulk` and `/{index}/_bulk`. On `/{index}/_bulk`, `{index}` is used only for
  actions without `_index`.
* `GET /` and `HEAD /` return a minimal identity response for client version detection. It
  reports version `8.19.0` as a fixed compatibility placeholder (it keeps the OTel exporter on its
  most widely compatible metrics format).
* Anything else: `404`; wrong methods: `405`.

===== Events

Event fields are the source document. Routing metadata (`action`, `index`, and `id`, `routing`,
`pipeline` when supplied) is stored at `metadata_target`
(default `[@metadata][elasticsearch_compat]`). `@metadata` is not written by outputs; copy what
downstream consumers need.

A numeric or digit-string `@timestamp` is read as epoch milliseconds, as Elasticsearch reads it
(the OTel exporter sends this form), with nanosecond precision.

===== Acknowledgments

* An item's `201` means the event was accepted by the Logstash queue, not that an output
  delivered it.
* `update` and `delete` are not supported: each gets an item-level `400`.
* A malformed body gets `400` and nothing from it is queued.
* If queuing fails mid-request: items already queued are `201`, the failing item `500`, the rest
  `503`. Clients retry these, so duplicates are possible.

===== Compression

Compressed request bodies (`gzip`, `deflate`, `x-gzip`, `x-deflate`) are always accepted;
`max_content_length` applies after decompression. Other encodings get `415`. Responses are
compressed (level 3, no size threshold) when the client accepts it, unless
`compression_enabled => false`.

===== Credentials

`Authorization` headers are accepted and ignored; no request ever gets `401` or `403`. Restrict
access with TLS client certificates (`ssl_client_authentication`) or at the network layer.

===== Monitoring

This input adds counters to its entry in the Logstash node stats API
(`GET /_node/stats/pipelines/<id>`): `bulk_requests`, `bulk_requests_rejected_overload` (`429`),
`bulk_requests_rejected_too_large` (`413`), `bulk_requests_rejected_unsupported_encoding`
(`415`), `bulk_requests_rejected_bad_request` (`400`), `bulk_items_failed`, and
`queue_submit_failures`. They are updated per request and visible within about a second. Disable
with `enable_metric => false`.

[id="plugins-{type}s-{plugin}-compression_enabled"]
===== `compression_enabled`

* Value type is <<boolean,boolean>>
* Default value is `true`

Compress responses when the client accepts gzip or deflate. Compressed requests are always
accepted regardless of this setting.

[id="plugins-{type}s-{plugin}-host"]
===== `host`

* Value type is <<string,string>>
* Default value is `"0.0.0.0"`

The address to listen on.

[id="plugins-{type}s-{plugin}-max_content_length"]
===== `max_content_length`

* Value type is <<number,number>>
* Default value is `104857600` (100 MB)

Maximum request body size in bytes, after decompression. Larger requests get `413`.

[id="plugins-{type}s-{plugin}-max_pending_requests"]
===== `max_pending_requests`

* Value type is <<number,number>>
* Default value is `200`

Requests waiting for a worker thread. Beyond this, new requests get `429` (retryable) before
anything is queued.

[id="plugins-{type}s-{plugin}-metadata_target"]
===== `metadata_target`

* Value type is <<string,string>>
* Default value is `"[@metadata][elasticsearch_compat]"`

Field where routing metadata is stored.

[id="plugins-{type}s-{plugin}-port"]
===== `port`

* Value type is <<number,number>>
* Default value is `9200`

The port to listen on.

[id="plugins-{type}s-{plugin}-ssl_certificate"]
===== `ssl_certificate`

* Value type is <<path,path>>
* There is no default value for this setting.

PEM certificate (chain). Requires `ssl_key`. Use either this or `ssl_keystore_path`.

[id="plugins-{type}s-{plugin}-ssl_certificate_authorities"]
===== `ssl_certificate_authorities`

* Value type is <<array,array>>
* Default value is `[]`

PEM certificate authorities that client certificates are checked against. Requires
`ssl_client_authentication` `optional` or `required`. Use either this or `ssl_truststore_path`.

[id="plugins-{type}s-{plugin}-ssl_cipher_suites"]
===== `ssl_cipher_suites`

* Value type is a list of <<string,string>>
* Default value is a modern list (TLS 1.3 suites and ECDHE AES-GCM/ChaCha20, then ECDHE AES-CBC),
  limited to those the JVM supports — the same as `logstash-input-http`.

Cipher suites to enable, in order of preference.

[id="plugins-{type}s-{plugin}-ssl_client_authentication"]
===== `ssl_client_authentication`

* Value can be any of: `none`, `optional`, `required`
* Default value is `"none"`

Whether to request (`optional`) or require (`required`) a client certificate. Needs
`ssl_certificate_authorities`, `ssl_truststore_path`, or a keystore that also holds trusted
certificates.

[id="plugins-{type}s-{plugin}-ssl_enabled"]
===== `ssl_enabled`

* Value type is <<boolean,boolean>>
* Default value is `false`

Serve HTTPS. Requires `ssl_certificate` and `ssl_key`, or `ssl_keystore_path`. Other `ssl_*`
settings with `ssl_enabled => false` are ignored with a warning.

[id="plugins-{type}s-{plugin}-ssl_handshake_timeout"]
===== `ssl_handshake_timeout`

* Value type is <<number,number>>
* Default value is `10000`

Time in milliseconds for an incomplete TLS handshake before the connection is closed.

[id="plugins-{type}s-{plugin}-ssl_key"]
===== `ssl_key`

* Value type is <<path,path>>
* There is no default value for this setting.

PEM private key in PKCS#8 format (convert PKCS#1 with
`openssl pkcs8 -topk8 -nocrypt -in key.pem -out key.pkcs8.pem`). Requires `ssl_certificate`.

[id="plugins-{type}s-{plugin}-ssl_key_passphrase"]
===== `ssl_key_passphrase`

* Value type is <<password,password>>
* There is no default value for this setting.

Passphrase of an encrypted `ssl_key`.

[id="plugins-{type}s-{plugin}-ssl_keystore_password"]
===== `ssl_keystore_password`

* Value type is <<password,password>>
* There is no default value for this setting.

Keystore password.

[id="plugins-{type}s-{plugin}-ssl_keystore_path"]
===== `ssl_keystore_path`

* Value type is <<path,path>>
* There is no default value for this setting.

PKCS12 or JKS keystore with the server key and certificate. Use either this or `ssl_certificate`.

[id="plugins-{type}s-{plugin}-ssl_keystore_type"]
===== `ssl_keystore_type`

* Value can be any of: `pkcs12`, `jks`
* There is no default value; when unset, `.p12`/`.pfx`/`.pkcs12` files are PKCS12 and others JKS.

Keystore format.

[id="plugins-{type}s-{plugin}-ssl_supported_protocols"]
===== `ssl_supported_protocols`

* Value type is <<string,string>>
* Allowed values are: `'TLSv1.1'`, `'TLSv1.2'`, `'TLSv1.3'`
* Default value is `['TLSv1.2', 'TLSv1.3']`

TLS versions to accept. The JVM disables `TLSv1.1` by default.

[id="plugins-{type}s-{plugin}-ssl_truststore_password"]
===== `ssl_truststore_password`

* Value type is <<password,password>>
* There is no default value for this setting.

Truststore password.

[id="plugins-{type}s-{plugin}-ssl_truststore_path"]
===== `ssl_truststore_path`

* Value type is <<path,path>>
* There is no default value for this setting.

PKCS12 or JKS truststore with the certificates client certificates are checked against. Requires
`ssl_client_authentication` `optional` or `required`. Use either this or
`ssl_certificate_authorities`.

[id="plugins-{type}s-{plugin}-threads"]
===== `threads`

* Value type is <<number,number>>
* Default value is the number of CPU cores

Worker threads that parse requests and queue events.
